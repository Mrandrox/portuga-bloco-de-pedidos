"# Portuga \u2014 Bloco de Pedidos para Windows\n\nAplicativo desktop Windows independente, usando a interface e os dados j\u00e1 existentes do Portuga.\n\n## Instalar\n\nAbra a execu\u00e7\u00e3o mais recente do workflow Windows e baixe o artefato `Portuga-Bloco-de-Pedidos-Windows`:\n\n**[Abrir builds e baixar Portuga para Windows](https://github.com/Mrandrox/portuga-bloco-de-pedidos/actions/workflows/windows-app.yml)**\n\nOs artefatos ficam dispon\u00edveis por 30 dias e exigem uma conta GitHub com acesso ao reposit\u00f3rio. A publica\u00e7\u00e3o como download direto em Releases ainda depende de autoriza\u00e7\u00e3o.\n\nO instalador cria atalhos no menu Iniciar e, se desejado, na \u00e1rea de trabalho. Os dados do aplicativo ficam no perfil local do Windows.\n\n## O que a vers\u00e3o Windows oferece\n\n- Janela desktop independente com o app atual de pedidos.\n- Tela de configura\u00e7\u00f5es para endere\u00e7o do card\u00e1pio, API de produtos, atendente, provedor e modelo.\n- Teste de disponibilidade do card\u00e1pio e da API.\n- Importa\u00e7\u00e3o de produtos por JSON, preservando os produtos cadastrados manualmente.\n- Envio de pedidos novos confirmados ao endpoint do atendente configurado.\n- Sele\u00e7\u00e3o das impressoras instaladas no Windows, impress\u00e3o de teste e impress\u00e3o autom\u00e1tica opcional de novos pedidos.\n- N\u00famero de recebimento do WhatsApp configur\u00e1vel no app desktop.\n- Espa\u00e7os informativos para Olist e WhatsApp Business API, aguardando a configura\u00e7\u00e3o dessas integra\u00e7\u00f5es.\n\n## Formato para importar o card\u00e1pio\n\nA API precisa estar acess\u00edvel por HTTPS e responder com JSON no formato abaixo, ou com uma lista equivalente. `name`/`nome`, `price`/`preco` e os campos de categoria aceitam nomes em portugu\u00eas ou ingl\u00eas. Categorias reconhecidas: lanches, por\u00e7\u00f5es/petiscos, pizzas e bebidas. Produtos sem nome ou pre\u00e7o positivo s\u00e3o ignorados.\n\n```json\n{\n  \"products\": [\n    { \"id\": \"x-burger\", \"name\": \"X-Burger\", \"price\": 25.9, \"category\": \"lanches\" }\n  ]\n}\n```\n\nProdutos importados recebem IDs `api-menu-*`; numa pr\u00f3xima importa\u00e7\u00e3o, s\u00f3 os produtos importados anteriormente s\u00e3o substitu\u00eddos. Produtos manuais permanecem no cat\u00e1logo.\n\n## Atendente e seguran\u00e7a\n\nO endpoint do atendente deve ser HTTPS, aceitar um `POST` de teste e receber pedidos confirmados em JSON. O pedido inclui cliente, itens, total, modalidade, endere\u00e7o quando aplic\u00e1vel, provedor escolhido e modelo selecionado. O backend do estabelecimento deve validar o pedido e guardar as chaves do provedor de IA. O app n\u00e3o pede nem armazena chaves secretas.\n\nO campo de URL apenas aponta para um servi\u00e7o. Para usar OpenAI, Anthropic ou Google, configure esse provedor no backend; o app desktop envia os pedidos ao endpoint e n\u00e3o chama a API do provedor diretamente.\n\n## Impressora t\u00e9rmica\n\nPareie a POS-58 no Windows e instale-a como uma impressora usando o driver compat\u00edvel com o modelo. Depois escolha a impressora em **Portuga \u2192 Configura\u00e7\u00f5es** e imprima um teste. O aplicativo imprime pela fila do Windows em papel de 58 mm. Impressoras sem driver ou que s\u00f3 aceitem Bluetooth SPP direto podem precisar de um driver/ponte Windows do fabricante.\n\nA impress\u00e3o autom\u00e1tica inicia quando um novo pedido \u00e9 salvo no aplicativo. A op\u00e7\u00e3o come\u00e7a desativada. O teste f\u00edsico depende da POS-58 estar pareada e instalada no computador.\n\n## Desenvolvimento\n\nRequer Node.js 22+.\n\n```bash\nnpm ci\nnpm start\nnpm run check\nnpm run dist:win\n```\n\nO instalador \u00e9 gerado em `dist/Portuga-Bloco-de-Pedidos-Setup.exe`. O GitHub Actions monta o instalador em Windows e anexa o arquivo \u00e0 Release publicada.\n"
