# Portuga Bloco de Pedidos Android 1.0.13

- Abas de Lanches, Petiscos, Pizzas e Bebidas no construtor de pedidos.
- Abas persistentes por cliente/comanda.
- Vários pedidos podem ser lançados para o mesmo cliente sem recriar a aba.
- Dados das abas ficam salvos localmente no aparelho.
- Mantida a ponte Bluetooth ESC/POS para impressoras POS-58.
- O APK é gerado automaticamente pelo GitHub Actions.
